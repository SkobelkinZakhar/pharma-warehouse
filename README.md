# Хранилище данных «Фармация»

Учебный проект по созданию хранилища продаж аптечной сети. Данные хранятся в SQLite, а отчёт строится в Loginom.

[Открыть ER-диаграмму](./Схема%20данных.md)

В центре схемы — продажи. Одна запись хранит количество и сумму для сочетания «дата + аптека + товар + час». Товар связан со справочником групп.

## Файлы

- `schema.sql` — таблицы, ключи и представления для отчётов.
- `load.py` — первоначальная и повторная загрузка с проверкой связей.
- `reports.sql` — выборки для куба и контрольные запросы.

## Запуск

Нужен Python с SQLite 3.37 или новее. Подготовьте папку с четырьмя исходными TXT-файлами практики в Windows-1251: `groups.txt`, `produces.txt`, `stores.txt`, `sales.txt`.

```powershell
python load.py --source 'путь к папке с исходниками' --db pharma.sqlite
```

Для полных выгрузок за затронутые дни можно добавить `--replace-days`. Повторная загрузка по умолчанию обновляет записи по составному ключу.

В Loginom создайте подключение SQLite к `pharma.sqlite`, импортируйте представление `sales_latest_four_months` и добавьте визуализатор «Куб». Измерения: месяц, аптека и группа товаров. Факты: количество и сумма с агрегацией «Сумма».
